## Description

**Any API. Any Data. Your Home Screen.**

Vulpino transforms JSON API endpoints into elegant iOS widgets in under 60 seconds. Paste a URL, pick your data, choose a template, and you're done.

**How It Works**
1. Paste any JSON API URL
2. Browse and select the data you want
3. Choose from 7 beautiful templates
4. Add the widget to your home screen

That's it. No coding, no complex setup, no account required.

**7 Templates for Every Use Case**

• Mono Stat — One big number that matters
• Dual Stat — Compare two values at a glance  
• Stat Stack — Dashboard of 3-5 key metrics
• Headline — Display text updates
• List — Show your top items
• Grid — Dense data in a compact view
• Timestamp — Track when data last changed

**Works With Your Favorite APIs**

• Weather services
• Stock and crypto prices  
• Smart home dashboards
• Analytics platforms
• Fitness and health data
• Custom business metrics
• Personal projects

**Privacy First**

• All data stays on your device
• API keys stored in secure Keychain
• No accounts, no tracking, no analytics
• We never see your data or requests

**Designed for Power Users**

• Custom HTTP headers and authentication
• Multiple widget sizes (small, medium, large)
• Automatic background refresh
• Offline caching for reliability
• Deep linking for quick access

---

**Important Notes**

Vulpino works with JSON APIs that you have access to. You're responsible for complying with the terms of service of any third-party APIs you connect to.

Data accuracy depends on the endpoints you configure. Always verify critical information at the source.
